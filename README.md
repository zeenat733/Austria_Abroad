# EasyTrip

Travel planning web app built during GMU's Software Engineering study abroad program in Vienna, Austria (Summer 2026).

## Features

- Interactive map with custom pins for trip locations
- Transit route planning between saved locations
- Calendar tab for scheduling events by date
- Expense tracker with currency conversion
- Total trip cost summary view
- PostgreSQL database with full schema and queries

## Tech Stack

JavaScript · React · Base44 · PostgreSQL

## Development

Built by a team of 3 using agile/scrum methodology across 5 sprints with 36 commits. Each sprint included planning, development, and a retrospective.
